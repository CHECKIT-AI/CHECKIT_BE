# 새 계약서 4건 전체 API 평가

2026-11-17. 이 수치는 가상 계약서와 전문가 미검토 정답 초안에 대한 **개발용 평가**다.

## 실행 조건

- FastAPI `TestClient`로 실제 회원가입·인증, 계약서 저장, 분석 job, 결과 조회, 계약서 삭제 API를 순서대로 호출했다. 실제 개발 DB, 고정 분류 모델, `employment_basic_v004` RAG, Gemini `gemini-3.1-flash-lite`를 사용했다. 브라우저 OCR과 외부 HTTP 서버 지연은 포함하지 않는다.
- 현재 설정 그대로 `dense_bm25_top5`, `top_k=5`, 적용일 `2026-11-01`, 상시 근로자 10명, 통상근로, 주 40시간으로 실행했다. 모든 계약서는 같은 한 페이지 텍스트를 두 번 독립 실행했다.
- 두 실행의 API 예측을 저장한 다음 `gold.csv`·`risk_gold.csv`를 작성했다. [첫 예측](api-predictions-2026-11-17.json)의 SHA-256은 `4329896ed6aa3a096e15754ba2554e07cdcda3e34a2ad0e0f649e8fc02b69bc3`이다. 각 예측의 입력 SHA-256이 해당 계약서 파일과 일치함을 확인했다.

## 필수 8항목 기재 여부

두 실행 모두 각 계약서의 `MISSING_*` 8개 코드와 `document_presence`를 빠짐없이 반환했다(**64/64**). 정답 초안은 `PRESENT` 22, `ABSENT` 7, `UNCLEAR` 3개로 구성된다.

| 정답 → 예측 | 첫 실행 | 재실행 |
| --- | ---: | ---: |
| `PRESENT → PRESENT` | 22/22 | 22/22 |
| `ABSENT → ABSENT` | 7/7 | 7/7 |
| `UNCLEAR → UNCLEAR` | 0/3 | 3/3 |
| **전체 일치** | **29/32 (90.6%)** | **32/32 (100%)** |

첫 실행의 오류 3개는 모두 N04의 미제출 별첨 A를 참조하는 휴일·연차·업무였다. 이를 `PRESENT`로 답했고, 재실행에서는 `UNCLEAR`로 답했다. 같은 설정에서도 판단 불가 분류가 흔들린다. 4건에 대한 평균 점수를 일반 정확도로 사용하지 않는다.

## 추가 위험과 법령 인용

| 원문에 넣은 위험 | 첫 실행 | 재실행 | 관찰 |
| --- | --- | --- | --- |
| N02 시급 9,000원 (`MINIMUM_WAGE`) | `CAUTION` | `NEEDS_CONFIRMATION` | 두 실행 모두 같은 코드 2건. 두 번째는 법령 근거 검증 실패로 최종 판단 보류 |
| N03 중도 퇴사 위약금 (`PRESET_PENALTY`) | `CAUTION` | `CAUTION` | 두 실행 모두 추가 `DISCOVERED_ISSUE`가 같은 내용을 중복 발견 |
| N04 8시간 근로·휴게 30분 (`INSUFFICIENT_BREAK`) | 없음 | 없음 | 두 실행 모두 놓침. 규칙은 `휴게 30분` 형식 등을 찾는데, 원문은 `휴게는 13:00~13:30` 형식 |

위 3개 위험 주제의 **후보 탐지율은 두 실행 모두 2/3**이다. 최종 `CAUTION`은 첫 실행 2/3, 재실행 1/3으로 달랐다. N02의 동일 저임금 표현 2개와 N03 위약금의 규칙·Gemini 중복은 결과 항목 중복 문제다.

재실행의 인용은 N01의 필수 항목에 근로기준법 제17조·시행령 제8조, N03 위약금에 제20조가 연결됐다. N02의 일부 누락 항목에는 제43조·제55조가 연결돼 있어 **근로계약서 명시 의무 자체의 직접 근거인지** 전문가 확인이 필요하다. N04는 인용 0건이어서 모든 최종 `status`가 `NEEDS_CONFIRMATION`이었다. 인용 건수는 첫 실행 N01~N04 순서대로 8·10·7·0건, 재실행 8·4·7·0건이다. 법령 검색의 Hit@k나 법률 판단 정확도는 이 4건만으로 측정하지 않았다.

이번 평가에서는 발견한 오류에 맞춰 모델·규칙을 다시 조정하지 않았다. 정답의 법적 타당성, 별첨 처리 기준과 인용 근거는 전문가 검토가 필요하다.
