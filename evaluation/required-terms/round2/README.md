# 새 가상 계약서 4건 API 평가 (2026-11-17)

이 디렉터리의 N01~N04는 이전 C01~C04와 다른 가상 계약서다. `gold.csv`의 32개 필수 항목과 `risk_gold.csv`의 3개 위험 항목은 **API 예측을 저장한 뒤** 원문을 기준으로 작성한 정답 초안이며, 노무·법률 전문가의 검토를 받지 않았다. 계약서 본문에는 실명·연락처·계좌번호가 없다.

| 사례 | 설계 목적 | 적용 조건 |
| --- | --- | --- |
| N01 | 대체 표현으로 8개 모두 기재 | 2026-11-01, 상시 10명, 주 40시간 |
| N02 | 임금 지급·휴일·업무 누락, 2026년 기준 미만 시급 | 동일 |
| N03 | 임금 계산·소정근로시간·연차·근무 장소 누락, 예정 위약금 | 동일. 주 40시간은 API 적용 조건이며 계약서에는 시간표가 없음 |
| N04 | 별첨 A를 참조하는 휴일·연차·업무, 8시간 근로에 30분 휴게 | 동일. 별첨 A는 API에 제출되지 않음 |

`PRESENT`는 항목의 실제 내용이 원문에 확인됨, `ABSENT`는 원문 전체에 해당 내용·외부 문서 참조가 없음, `UNCLEAR`는 참조된 별첨의 내용이 없어 확인할 수 없음을 뜻한다. 기재 사실과 법령 적용·적법성은 별개다. 별첨 참조를 `UNCLEAR`로 두는 기준도 전문가 확정 전이다.
