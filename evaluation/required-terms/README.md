# 필수 근로조건 8항목 평가 세트 (초안)

새 계약서 4건의 독립 API 평가는 [2차 평가](round2/report-2026-11-17.md)를 참고한다.

가상 계약서 4건과 계약서별 8항목의 기재 여부 정답 **초안**이다. 실제 근로계약이나 법률 자문용 문서가 아니다. 법률 전문가가 아직 검토하지 않았으므로 `gold.csv`의 `review_status=PENDING_EXPERT_REVIEW`를 전문가 확정 정답으로 취급하지 않는다. 서비스 입력은 각 `*.txt`의 계약서 본문이며, 정답·해설과 사업장 조건은 분석 모델에 제공하지 않는다.

| ID | 계약서 | 설계 목적 | 적용일 | 사업장 조건 |
| --- | --- | --- | --- | --- |
| C01 | `C01-complete.txt` | 8항목 모두 기재 | 2026-11-01 | 상시 근로자 10명, 주 40시간 통상근로, 부속 문서 없음 |
| C02 | `C02-missing-a.txt` | 임금 계산·지급, 휴일, 근무 장소 누락 | 2026-11-01 | 상시 근로자 10명, 주 40시간 통상근로, 부속 문서 없음 |
| C03 | `C03-missing-b.txt` | 임금 구성, 소정근로시간, 연차, 업무 누락 | 2026-11-01 | 상시 근로자 10명, 주 40시간 통상근로 예정이나 계약서에는 시간표 없음, 부속 문서 없음 |
| C04 | `C04-unconfirmed-attachment.txt` | 제출되지 않은 부속합의서 참조 | 2026-11-01 | 상시 근로자 10명, 주 40시간 통상근로, 부속합의서 A 제출 여부 미확인 |

`gold.csv`는 `app/analysis_rules.py`의 `REQUIRED` 코드 8개를 그대로 사용한다. `PRESENT`는 해당 내용의 문구가 제출된 계약서에서 확인됨, `ABSENT`는 제출된 전체 문서에서 찾지 못함, `UNCLEAR`는 참조 문서의 제출·내용을 확인할 수 없어 기재 여부를 확정할 수 없음을 뜻한다. 이는 **기재 사실**만의 라벨이며 문구의 적법성·충분성, 서면 교부 여부 또는 법 위반 확정 판정이 아니다. `PRESENT`·`UNCLEAR`의 `evidence`는 계약서의 정확한 부분 문자열이고 `ABSENT`는 비워 둔다. `UNCLEAR`의 `needed_to_resolve`를 확인한 뒤 재라벨링한다.

법령 기준: [근로기준법 제17조 제1항·제2항](https://www.law.go.kr/lsLinkProc.do?joNo=001700&lsNm=%EA%B7%BC%EB%A1%9C%EA%B8%B0%EC%A4%80%EB%B2%95&mode=11)은 임금, 소정근로시간, 휴일, 연차 유급휴가 등의 명시와 임금 구성·계산·지급 방법 등의 서면 교부를 규정한다. [근로기준법 시행령 제8조 제1호](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0008&lsiSeq=270551&urlMode=lsScJoRltInfoR)는 취업 장소와 종사 업무를 명시 사항으로 정한다. 연차 등의 실제 적용·산정은 [근로기준법 제11조·제18조 제3항·제60조](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20261002&lsiSeq=290781&urlMode=lsInfoP)와 해당 시행 시점·상시 근로자 수·주 소정근로시간을 별도로 확인해야 한다. 이 세트는 2026-11-01 적용, 10명·주 40시간 사례로 고정했고, 사업장 조건은 평가 메타데이터이지 계약서의 숨은 문구가 아니다.

실제 평가에 투입하기 전에 노무·법률 전문가가 각 행의 라벨, 법령 시행 버전, 적용 요건, 근거 문구를 독립 검토하고 `review_status`를 확정해야 한다. 미제출 부속 문서 참조의 `UNCLEAR` 처리도 그때 합의한다. 실계약서·원자료는 여기에 넣지 않는다.
